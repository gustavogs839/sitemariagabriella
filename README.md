# Site Gabriella Beauty Studio

Site institucional moderno para **nail designer** e **lash designer**, feito em HTML, CSS e JavaScript.

## Como abrir

Basta abrir o arquivo `index.html` no navegador.

## O que personalizar

Edite no `index.html`:

- número do **WhatsApp**: procure por `5511999999999`
- link da **localização**: procure por `https://maps.app.goo.gl/`
- usuário do **Instagram**
- **valores** dos serviços
- textos e informações do atendimento

## Galeria de fotos

A seção `Galeria` está pronta com blocos visuais. Se quiser usar fotos reais, substitua os blocos por imagens suas no `index.html`.

## Estrutura

- `index.html` → conteúdo do site
- `styles.css` → visual e responsividade
- `script.js` → menu mobile e detalhes interativos
